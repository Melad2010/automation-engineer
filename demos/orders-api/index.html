Brindlecove Supply Orders API

Python · FastAPI · SQLAlchemy · Alembic · pytest

API referenceHow it behavesopenapi.json

Static reference for a sample service. The service itself runs locally with one command: python -m app serve --seed. Brindlecove Supply is a fictional wholesale company; all data here is invented.

22 operations. Sign in with POST /auth/login, then send Authorization: Bearer <token>. Every error uses one body shape with a request_id.

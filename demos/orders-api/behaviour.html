Static reference for a sample service. The service itself runs locally with one command: python -m app serve --seed. Brindlecove Supply is a fictional wholesale company; all data here is invented.

Every test gets its own SQLite database file built by the real migrations. The race tests start several threads at the same instant: two orders for the last unit, twelve buyers for five units, eight HTTP requests for four units, six retries with one idempotency key, two cancels of one order.

Order status and stock

Stock per product: on hand (in the warehouse), reserved (promised to confirmed orders) and available = on hand − reserved. Each change is a single conditional update in the database and writes an audit row.
